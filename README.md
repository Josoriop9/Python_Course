## Full syllabus

### Week 0 · Functions, Variables ▶️
- `def`, parameters, `return` vs `print`, default values, variable scope.
- Variables, `int`, `float`, `str`, f-strings, `input()`. ✅
- **Problem Set 0:** Indoor Voice, Playback Speed, Making Faces, Einstein, Tip Calculator.

### Week 1 · Conditionals ✅
- `if / elif / else`, `and`, `or`, `not`, comparisons, `match`.
- **Problem Set 1:** Deep Thought, Home Federal Savings Bank, File Extensions, Math Interpreter, Meal Time.

### Week 2 · Loops ✅
- `for`, `while`, `range`, lists, strings, dictionaries.
- Patterns: counter, accumulator, champion, frequency count.
- **Problem Set 2:** camelCase, Coke Machine, Just setting up my twttr, Vanity Plates, Nutrition Facts.

### Week 3 · Exceptions
- `try / except / else`, `ValueError`, `KeyError`, re-prompting until input is valid.
- **Problem Set 3:** Fuel Gauge, Felipe's Taqueria, Grocery List, Outdated.

### Week 4 · Libraries
- `import`, `random`, `statistics`, `sys.argv`, installing packages with `pip`, calling APIs, JSON.
- **Problem Set 4:** Emojize, Frank Ian and Glen's Letters, Adieu Adieu, Guessing Game, Little Professor, Bitcoin Price Index.

### Week 5 · Unit Tests
- `assert`, `pytest`, testing normal cases, edge cases and errors.
- **Problem Set 5:** Testing my twttr, Back to the Bank, Re-requesting a Vanity Plate, Refueling.

### Week 6 · File I/O
- `open`, `with`, reading and writing text, CSV.
- **Problem Set 6:** Lines of Code, Pizza Py, Scourgify, CS50 P-Shirt.

### Week 7 · Regular Expressions
- `re.search`, patterns, validating emails and formats.
- **Problem Set 7:** NUMB3RS, Watch on YouTube, Working 9 to 5, Regular, um, Expressions?, Response Validation.

### Week 8 · Object-Oriented Programming
- Classes, objects, methods, `__init__`, properties.
- **Problem Set 8:** Seasons of Love, Cookie Jar, CS50 Shirtificate.

### Week 9 · Et Cetera
- `set`, type hints, docstrings, list comprehensions, `map`, `filter`, generators.

### Final Project
- A project of my own that uses everything from the course.
